# 市场功能端到端审计（2026-07-22）

## 范围

- iOS：市场首页、指数详情、成分股入口、缓存、轮询、WebSocket、图表和可访问性。
- 服务端：Dashboard、指数成分股、图表、Redis 刷新队列、行情时间戳及运行态。
- 证据：当前模拟器截图、代码审查、生产接口抽样和测试结果。

## 总体判断

功能主链路可用，信息结构清楚，实时行情与降级缓存也已有较完整基础；但数据契约仍混合“行情发生时间、采集时间、页面生成时间”，图表会在历史数据缺失时合成分钟时间轴，刷新队列也缺少去重。这三项会直接影响用户对行情真实性的判断，应优先整改。

## 流程步骤

1. 市场首页：中国区域可正常加载，区域、指数表格和涨跌色彩层级清楚；健康度为“可用但被全局更新失败浮层遮挡”。证据：`01-market-china.png`。
2. 上证指数详情：价格、关键数据、区间选择与数据来源齐全；健康度为“可用但图表覆盖不足且浮层遮挡分享区”。证据：`02-shanghai-detail.png`。
3. 成分股详情：接口和代码链路已检查，交互截图因当前模拟器缺少可用触控控制接口未完整捕获；健康度为“数据可用，但首屏可能先显示过期值且客户端不展示 staleSymbols”。

## 主要问题

### P0/P1：数据可信度

1. 服务端允许未来时间戳进入聚合。抽样中微盘股时间为当天 15:00，而检查时间约 10:42，导致 Dashboard 的 latestTimestamp 指向未来；现有 stale 判断只处理“年龄过大”，不会拒绝未来数据。
2. 日内图表与实时价不同步。上证指数图表接口返回的 39 个点停在上一交易时段，iOS 随后会把无时间信息的 trend 数组按连续分钟合成时间轴，视觉上像真实分时走势。
3. 成分股刷新是异步的：接口先返回旧值，再把 staleSymbols 入队；iOS 模型没有 staleSymbols 字段，也不会在刷新完成后自动重取，因此用户可能停留在旧值。
4. 涨跌字段语义不统一。生产者在交易中把 changePercent 作为“相对开盘”，Dashboard/成分股接口又改成“相对昨收”，其他消费者仍可能得到不同语义。

### P1：服务稳定性

5. 刷新队列缺少去重和背压。同一成分股接口连续请求会重复投递相同 stale symbol；本次三次抽样后队列新增 16 条任务。
6. 成分股名单缓存命中时仍把 asOf 写成当天日期，而不是实际抓取日期，容易让客户端误以为名单和行情都是当天重新获取。
7. Dashboard 每次请求并发读取多组图表，实测约 59–289ms；成分股接口约 195–206ms。当前规模可用，但多客户端轮询时会放大数据库压力。

### P2：iOS 性能与体验

8. 单个 `@Observable MarketStore` 承载 Dashboard、全部图表、成分股和实时状态；每 150ms 批量更新后替换整个 Dashboard，可能造成首页大范围重绘。此项为代码层推断，尚未用 Instruments 量化。
9. 进入任意详情后会后台预加载除“1日”外的六个周期，增加网络、解码和字典状态更新；多数用户未必会查看这些周期。
10. 时间格式化函数在渲染路径中重复创建 `DateFormatter`/`ISO8601DateFormatter`，实时更新时是不必要的主线程成本。
11. 全局“更新失败”卡片覆盖市场标题、代码、走势图或分享按钮。部署状态不应压住核心行情任务。
12. 大量固定字号、单行截断和固定宽度，在较大动态字体下存在裁切风险；截图不能证明完整 VoiceOver、动态字体和对比度合规。

## 优点

- 市场区域与指数层级明确，详情页信息顺序自然。
- WebSocket 有重连、心跳与 150ms 合并刷新，避免逐条消息立即刷新。
- 图表有稳定时间戳 ID、错误重试、减少动态效果支持和拖动查看能力。
- 服务端已有来源仲裁、健康字段、缺失字段和缓存降级。
- iOS 89 项测试全部通过；市场服务端相关 Go 测试通过。

## 建议顺序

1. 统一 Quote 契约：明确 `providerTimestamp`、`receivedAt`、`changeVsPreviousClosePercent`、`changeVsOpenPercent`，拒绝超过当前时间容差的行情时间。
2. 修复图表真实性：服务端持续写入当前交易日分钟 K；客户端不再给无时间的 trend 合成分钟时间轴，覆盖不足时明确显示“数据不足”。
3. 为刷新队列增加 symbol 级 SET NX 去重、TTL、队列年龄与失败指标；成分股 stale 刷新完成后让客户端自动重取。
4. 拆分 MarketStore 的 Dashboard/Chart/Constituent 观察面，只预加载相邻周期并缓存格式化器。
5. 将部署状态默认收起并避开核心内容；补动态字体、VoiceOver 和端到端 UI 测试。

## 证据限制

- 本次没有 Instruments trace，因此 SwiftUI 性能结论是代码支持的风险，不是实测 CPU/掉帧结论。
- 当前环境没有可用的模拟器触控接口，未完整捕获“指数详情滚动到成分股并进入个股详情”的连续截图。
